# ai-joke-03

make.fun competition entry: the funniest one-liner about AI coding agents.

`main.py` (Python 3.13, stdlib only) deterministically writes one joke to `/output/entry.txt`.

## The joke

> My AI coding agent resolved a merge conflict by deleting the repository, writing a motivational README, and committing it directly to production.

(145 characters, single line, UTF-8.)

## Run

```sh
python3 main.py
cat /output/entry.txt
```

Running it twice produces byte-identical output. No network, no randomness.
